# Readest Preview 阅读 AI（基于 20010）

## 三个入口
1. 长按选择文字 → `AI 解释`：讲白话、举例、拆解论证、术语、翻译并解释。原 PDF / EPUB 和 PDF 重排共用现有 Annotator。
2. 阅读页右下角圆形 `AI` 按钮（20020 起取代阅读顶栏按钮）：当前章节、截至打开面板的已读部分、明确选择全书。原文在本机逐节提取和关键词排序，不调用 embedding API；选出最多 14 段 / 14000 字符，再确认发送。
3. 听书迷你卡片 / 完整面板 → `AI · 刚才那段`：最多最近 8 个朗读文本块，解释、概括、原文记录；可暂停原文、朗读 AI 解释后继续同一会话。

## 配置
阅读助手内 `AI 设置` 打开原设置 AI 页。启用 AI，推荐 OpenAI Compatible：填 API 版本根地址（如 https://api.example.com/v1）、API Key、模型 ID；embedding 可留空。模型列表只在点击刷新时请求，手填模型不被列表覆盖。支持现有 Ollama / AI Gateway provider，不改锁定依赖。

## 数据发送
打开助手、点击解释类型、本地检索、保存原文不会发送 AI 请求。必须先准备原文，再看发送预览，最后点击确认。仅发送问题、选出的原文段落和最近同范围最多 2 轮问答（预览中可展开查看）。换范围/防剧透策略后不携带旧范围历史。默认 AI 关闭，不预填密钥。

语音解释另需勾选同意将 AI 答案发给微软 Edge 语音服务。解释使用专用 AudioContext 与中文 Xiaoxiao 声音，不销毁/重置原文客户端，不修改原文语速/位置。语音分段最多 500 字符，特殊 XML 字符转义。取消/关闭停止播放，迟到的合成结果丢弃；既有 EdgeSpeechTTS 不提供关闭单次合成 websocket 的接口，已发出的请求可能仍由上游完成。只在语音正常完成、面板未关闭、原控制器未替换/终止且仍暂停时继续原文。解释失败/取消不自动续播。

## 引用与笔记
CFI 由现有 Foliate view + 原始文档 Range 生成，绝不从 AI 回复生成锚点。只有本轮发送过且有真实 CFI 的来源编号可点击。重排引用经原服务跳页后，把原文范围投影到重排段落并滚动/闪示；无法证明映射时只定位物理页并提示。模型仍可能误解原文；引用可定位不等于推论已验证。AI 回答以纯文本安全渲染，不执行 HTML。笔记走原 booknotes/saveConfig，标注【AI 解读，仅供参考】并保留原文。

## 限制
- 本机关键词检索而非语义 embedding，跨语言/代词/抽象问题可能漏召回；无关键词匹配会提示，不能当作“全书不存在”。全书按需扫，最多 2000 分节，无持久全文索引，重复问题会重扫。
- PDF 目录可解析时按章节，无目录回退单物理页；防剧透以物理页边界，当前页可能含尚未听到的文字。EPUB 当前分节以可解析 CFI 末端截断，失败则排除该分节。模型既有知识仍可能造成剧透，不能保证绝对零剧透。
- 超长选区每段截取最多 4000 字符，界面明确提示并提供外发预览；扫描页、图片和复杂公式不做 OCR（OCR 已评估后暂缓，当前版本不含）。
- 听书记录从宿主挂载后的真实位置事件采集，首次打开最多当前文本块；不猜测之前听过的历史，不跨书或跨控制器继承。它是文本块记录，不承诺“最近 N 秒”或全段已听完。
- 按钮交互首版；无麦克风语音识别/唤醒词，不新增锁屏 AI 控制。
- API Key 沿用原本机 settings.json 保存机制（不是新增安全密钥库），未列入当前 replica settings 同步白名单；用户自建云服务可见所发送原文。保存 AI 笔记后会按用户原笔记同步配置同步。
- 不自动重试 AI 请求，单次请求超时 120 秒；原生 HTTP 已有任意用户配置 endpoint 权限，web 版本仍受 API 服务 CORS 限制。

## 验证
新增测试涵盖真实 Foliate CFI 往返、关键词检索/引用白名单/边界截断、真实 AI SDK 的模拟兼容 SSE 传输、429 不重试、请求取消/错误、原文笔记保存、同范围追问和历史隔离、听书上下文会话隔离、独立语音和原会话恢复保护。所有测试以公开合成内容/现有公开 PDF 样本运行，没有发送用户书籍或真实密钥到外部 AI。APK 实际模型调用/播放串音/后台行为仍须安装新版验收。

## 20020 变更
### 悬浮按钮：听书 + AI（圆形，微信读书式）
- 阅读页右下角两个圆形按钮：上方“听书/暂停/继续”，下方“问这本书”。点听书沿用原有的朗读入口（重排 PDF 从当前重排页开始），点 AI 打开助手。
- **只在纯阅读状态显示**。以下任一情况出现即整体隐藏（`inert` + `aria-hidden` + 透明，不接收触摸，也不进入焦点顺序）：点屏幕唤出的顶栏/底栏（含字体、颜色、进度面板）、未固定的侧栏/笔记本、设置对话框、以及任何自带 `data-capture-blocking-overlay` 的弹层/面板/弹窗（Dialog、ModalPortal、Popup、注释弹窗等）。关闭后自动恢复。
- 因此不再需要“测量并避让”其它控件；唯一保留的避让是听书迷你播放条（可见时按钮上移）。这从结构上消除 D01 一类“悬浮钮盖住/吞掉下层触摸”的问题。
- 判定逻辑：`useReadingChromeHidden`（读取 hoveredBookKey / 侧栏 / 笔记本 / 设置 store，加一个对 `document.body` 的 MutationObserver 监听弹层标记，40ms 去抖）。

### 检索与确认
- 本地检索由“词频累加”改为 **BM25**（含长度归一化），命中后补上前后相邻段落并按阅读顺序排列，仍受 14 段 / 14000 字符上限。
- **云端检索词扩展**（默认开，可在面板关闭）：检索前向已配置的云端模型发送**仅用户问题**（不含任何书中文字，≤500 字、≤200 token、不重试），让它补同义词/中英对应词，再并入本地检索。失败或超时静默退回本地词。选段解释和听书不使用。
- **分级确认**：发送预览里可勾选“本次阅读中，这本书同一范围、同一服务不再逐次确认”。仅存于内存（重启应用即失效），按 书 + 范围 + 防剧透策略 + 目标服务 隔离，**全书范围永不可跳过**。跳过时仍会构建并显示预览，只是省去再点一次。
- **追问不再限 2 轮**：改为按字数预算（最近同范围问答合计 ≤6000 字符），底层安全上限 20 条。

### 本书助手历史
- 每次答案自动存入本机（localStorage，按书哈希隔离，最多 50 条 / 约 40 万字符，不同步、不上传）。保存问题、答案、范围，以及**被引用且有真实 CFI** 的来源，可从历史里再次“回到原文”。支持单条删除、清空本书历史。
- 它与笔记本里的 Reedy 对话库是两套存储，互不读取。

### 上次读到哪 / 前情提要
- 阅读时每 ≥20 秒（及切后台/关闭时）把当前位置（CFI、章节名、页码、百分比、时间）写入本机，不同步。预览（深链）模式不记录。
- 重新打开书时，若距上次阅读 ≥6 小时，顶部出现“欢迎回来 · 上次读到：章节 · 第 N 页 · X% · N 天前”卡片，20 秒自动消失；翻页离开原位置、唤出工具栏或弹层时也会收起。**卡片本身不联网、不调用 AI**。
- 点“前情提要”打开助手（范围固定为“已读部分”、**强制防剧透**、固定提问）：取最近 6 段 + 此前内容均匀抽样 8 段，仍须“准备→预览→确认”才会发送，并明确提示“不是通读全文”。可点“改为自己提问”转为普通问答。

## 20020 限制
- OCR 暂缓：扫描版 PDF 仍只能回退原版显示，AI 对无文字层页面无内容可用。
- 前情提要依赖已读范围的抽样，长书早期细节可能缺失；PDF 防剧透仍以物理页为边界。
- 欢迎卡片的位置记录是设备本地的，换设备不会带过去（与阅读进度同步无关）。
- 云端检索词扩展会产生一次额外的小请求（仅含问题）；使用 Codex OAuth 时同样走订阅额度。
- 悬浮按钮靠 `data-capture-blocking-overlay` 判定弹层：第三方/新增弹层若没有这个标记，按钮不会自动隐藏。
- 以上均只做了单元/组件测试，未装机真机验证。
