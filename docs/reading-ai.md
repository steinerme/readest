# Readest Preview 阅读 AI（基于 20010）

## 三个入口
1. 长按选择文字 → `AI 解释`：讲白话、举例、拆解论证、术语、翻译并解释。原 PDF / EPUB 和 PDF 重排共用现有 Annotator。
2. 阅读顶栏 → `问 AI`：当前章节、截至打开面板的已读部分、明确选择全书。原文在本机逐节提取和关键词排序，不调用 embedding API；选出最多 14 段 / 14000 字符，再确认发送。
3. 听书迷你卡片 / 完整面板 → `AI · 刚才那段`：最多最近 8 个朗读文本块，解释、概括、原文记录；可暂停原文、朗读 AI 解释后继续同一会话。

## 配置
阅读助手内 `AI 设置` 打开原设置 AI 页。启用 AI，推荐 OpenAI Compatible：填 API 版本根地址（如 https://api.example.com/v1）、API Key、模型 ID；embedding 可留空。模型列表只在点击刷新时请求，手填模型不被列表覆盖。支持现有 Ollama / AI Gateway provider，不改锁定依赖。

## 数据发送
打开助手、点击解释类型、本地检索、保存原文不会发送 AI 请求。必须先准备原文，再看发送预览，最后点击确认。仅发送问题、选出的原文段落和最近同范围最多 2 轮问答（预览中可展开查看）。换范围/防剧透策略后不携带旧范围历史。默认 AI 关闭，不预填密钥。

语音解释另需勾选同意将 AI 答案发给微软 Edge 语音服务。解释使用专用 AudioContext 与中文 Xiaoxiao 声音，不销毁/重置原文客户端，不修改原文语速/位置。语音分段最多 500 字符，特殊 XML 字符转义。取消/关闭停止播放，迟到的合成结果丢弃；既有 EdgeSpeechTTS 不提供关闭单次合成 websocket 的接口，已发出的请求可能仍由上游完成。只在语音正常完成、面板未关闭、原控制器未替换/终止且仍暂停时继续原文。解释失败/取消不自动续播。

## 引用与笔记
CFI 由现有 Foliate view + 原始文档 Range 生成，绝不从 AI 回复生成锚点。只有本轮发送过且有真实 CFI 的来源编号可点击。重排引用经原服务跳页后，把原文范围投影到重排段落并滚动/闪示；无法证明映射时只定位物理页并提示。模型仍可能误解原文；引用可定位不等于推论已验证。AI 回答以纯文本安全渲染，不执行 HTML。笔记走原 booknotes/saveConfig，标注【AI 解读，仅供参考】并保留原文。

## 限制
- 本机关键词检索而非语义 embedding，跨语言/代词/抽象问题可能漏召回；无关键词匹配会提示，不能当作“全书不存在”。全书按需扫，最多 2000 分节，无持久全文索引，重复问题会重扫。
- PDF 目录可解析时按章节，无目录回退单物理页；防剧透以物理页边界，当前页可能含尚未听到的文字。EPUB 当前分节以可解析 CFI 末端截断，失败则排除该分节。模型既有知识仍可能造成剧透，不能保证绝对零剧透。
- 超长选区每段截取最多 4000 字符，界面明确提示并提供外发预览；扫描页、图片和复杂公式不做 OCR。
- 听书记录从宿主挂载后的真实位置事件采集，首次打开最多当前文本块；不猜测之前听过的历史，不跨书或跨控制器继承。它是文本块记录，不承诺“最近 N 秒”或全段已听完。
- 按钮交互首版；无麦克风语音识别/唤醒词，不新增锁屏 AI 控制。
- API Key 沿用原本机 settings.json 保存机制（不是新增安全密钥库），未列入当前 replica settings 同步白名单；用户自建云服务可见所发送原文。保存 AI 笔记后会按用户原笔记同步配置同步。
- 不自动重试 AI 请求，单次请求超时 120 秒；原生 HTTP 已有任意用户配置 endpoint 权限，web 版本仍受 API 服务 CORS 限制。

## 验证
新增测试涵盖真实 Foliate CFI 往返、关键词检索/引用白名单/边界截断、真实 AI SDK 的模拟兼容 SSE 传输、429 不重试、请求取消/错误、原文笔记保存、同范围追问和历史隔离、听书上下文会话隔离、独立语音和原会话恢复保护。所有测试以公开合成内容/现有公开 PDF 样本运行，没有发送用户书籍或真实密钥到外部 AI。APK 实际模型调用/播放串音/后台行为仍须安装新版验收。
