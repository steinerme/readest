# PDF 文字重排（单栏文字版）

## 入口与使用

打开 PDF，原版视图恢复完成后默认进入文字重排。轻点正文唤出顶部工具栏，「切换为 PDF」回到对应原文件页；原版顶部直接提供「切换为重排」，不必进入更多菜单。手动切原版后，本次阅读不会自动抢回重排；重新打开 PDF 仍默认重排。

- 当前原文件页码进入，竖向滚动读本页；上一页、下一页或输入原文件页码跳转。
- 原版与重排复用同一 HeaderBar、FooterBar、目录侧栏、笔记本和设置弹窗；没有第二套重排上下栏。顶栏切换按钮随模式显示「切换为 PDF／切换为重排」，其余按钮、图标和服务相同。
- 底栏 A 面板沿用同一字号、行距、页边距、字体设置，重排正文实时读取同一 ViewSettings；亮度/主题、目录、进度/页码、听书按钮沿用原服务。轻点正文同时显示/隐藏原版上下栏，滚动或选字不误触发。
- Android返回键沿用原阅读器的优先级：先关闭顶层弹窗/面板或栏，再目录/笔记本，再返回书架；关闭按钮沿用原书籍关闭/保存服务。重排不再单独注册返回键或焦点陷阱。
- 「返回对应原页」是独立操作：立即退出重排，再请求原版跳页；失败仅toast提示，不允许跳页卡死阻止用户退出。
- 原文件页码含封面；示例书 PDF 第17页对应印刷第16页。
- 底部共用耳机按钮从当前物理页开始。启动后显示与原版共用的听书卡片和完整听书面板：上一句/下一句、播放/暂停、停止，展开卡片或「播放设置」可调整倍速、声音、定时，以及语音引擎支持时的进度拖动/歌词位置。无时间线引擎不显示伪造的时间进度。当前真实朗读词/句高亮，自动滚动并跟随进入下一物理页。
- 手动翻页、滑动、鼠标滚轮或导航键暂停视觉跟随，不暂停声音；「回到正在朗读」恢复跟随。切回 PDF 不停止音频，返回书架沿用原有退出行为。
- 高亮通过控制器实际 Range 与 PDF 字符流来源映射，不按全文重复句搜索、不模拟逐字时间戳；语音引擎无词边界则以句子标示，文字层经转换不一致时不冒险高亮。听书仍采用原有 PDF 文字层顺序，复杂版式不保证与视觉重排顺序一致。
- 重排选字调用同一个批注/字典/翻译/复制工具栏。高亮和笔记只接受经来源映射证明的原PDF文字层Range/CFI；重复句不按字符串搜索。原书批注映射显示到重排文字并可打开编辑；源错配、被重建改变顺序的非连续选区禁用保存定位工具，不制造笔记锚点。选字朗读使用原PDF实际Range。
- 原版已禁用的PDF全文翻译仍在两模式保持同样禁用；这不等于凭空支持原版没有的功能。图像、双页摊开等原PDF专用渲染选项不改变文字重排的单栏边界。
- 不连续拼接跨页段落、不生成新书、不修改 PDF。每页导航同步原版实际位置，使目录、书签和阅读进度操作同一本书；书签始终保存可见重排页对应的原CFI，不误存已播放到的其他页。
- 同一App会话内记忆每本书重排页码（sessionStorage，不含正文）；字号/行距使用原版持久化设置而非独立重排设置。缓存仅打开期间有效，不保存段内滚动偏移。

## 范围

适用：有正常文字层的单栏横排 PDF，正文和独立小字注释。
不支持：OCR、复杂双栏结构还原、公式/表格/图片重建、AI 纠错或改写。
设置内说明适用局限，空页和旋转页明确回退原版。页眉/页脚仅保守去除孤立边缘数字页码，不笼统删除重复文字。
可能多栏的检测只是启发式，不能发现所有复杂布局。文字层缺字、编码问题或 PDF 绘制成图像的文字无法靠此功能补回。

## 实现

- `foliate-js/pdf.js` 的 section 添加 `getReflowText`，复用已打开的 PDF worker，不另开整本文档、不渲染 canvas。
- 坐标从 crop-box 原点归一化；重排函数依据基线与横向位置合并文字、小上标、斜体及中英文换行。
- 通过独立原页间距/字体判断段落及小字注释，React 以纯文本渲染，PDF 内容不作为 HTML 执行。
- 每次只提取所选原页，内存最多缓存12页，异步请求失效保护避免快速翻页显示旧内容。
- 重排正文挂在原阅读器内容层z5，而非z120全屏弹窗；原版HeaderBar/FooterBar/Sidebar/Annotator保持原位置和实例。原PDF保持服务状态但正文inert/aria-hidden避免重复无障碍。重排不改变原书format或伪造CFI；导航使用官方view.goTo并确认fixed-layout物理index，原服务relocate驱动可见页。
- `reading-polish.patch` 包含应用全部修改；`foliate-reflow.patch` 必须在锁定的 foliate-js 子模块内另行应用。云端 workflow 已接入，两者缺一不可。
